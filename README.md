# Quick Start

> [!CAUTION]
> mecab 기능을 원활히 사용하기 위해서는 다음 설치가 필요합니다.
> 환경변수가 설정되어 있어야 합니다.
> https://shogo82148.github.io/mecab/

> [!CAUTION]
> 환경 변수에 OpenAI api key가 설정되어 있는 경우, open ai를 활용한 기능이 가능해 집니다.

```bash
npm install
npm run serve
```

1. `npm install` 로 종속성 설치.

2. `npm run serve` 로 실행. (혹은 start.bat 실행)

3. `localhost:3000` 에 접속 (자동으로 열리지 않을 경우)

4. 번역할 영상을 추가하고, 자막을 입력한 뒤 공유할 수 있습니다.

5. 공유 링크는 일반적으로 `8192`길이까지 가능합니다.

   > 혹은, 공개적으로 업로드해 단축된 `URL`로 공유할 수 있습니다.

# 기능

- 유튜브 링크를 등록해 해당 영상을 번역할 수 있습니다.

## 타임라인 작성

- `nodejs-whisper` 라이브러리를 통해 `인식한 음성`으로 초안을 작성 할 수 있습니다.

- 해당 유튜브 영상에 자막이 지원되는 경우에는 `자막 정보`를 가져와서 작성 할 수 있습니다.

- 자막과 음성인식 결과를 비교해서 볼 수 있습니다. 해당 데이터를 클릭해 그 부분을 재생할 수 있습니다.

- OPENAI_API_KEY가 환경변수에 등록된 경우 openAI의 `whisper`모델을 통해 음성을 인식합니다.

- 만약, 해당 영상의 대본 정보가 있는 경우에는 텍스트를 입력해, `음성인식 결과를 보정`할 수 있습니다.

## 단어 등록

문장을 드래그 해서 단어를 등록 할 수 있습니다. 현재 `한자` 또는 `한자 + 히라가나` 조합의 형태만 등록이 가능합니다.

한번 단어를 등록한 후에는, 등록된 단어를 드래그 시, 해당 표기를 기준으로 모든 문장이 검색됩니다. 검색된 문장을 통해 현재 등록된 단어정보로 바로 등록이 가능합니다. 또는, 드래그된 부분(단어가 등록되지 않은 경우)이 이미 등록된 단어의 표기가 있는 경우 바로 추가가능한 단어들이 목록에 표시됩니다.

단어 등록시에는, 읽기를 `히라가나로만` 입력해야 합니다. 현재 드래그 된 부분이 표기로 등록됩니다. 입력폼은 표기에 포함된 한자위에 input이 생성되며, 해당 부분에 표기에 있는 `히라가나를 제외한 입력`이 요구됩니다. 한글로 입력할 경우 자동으로 히라가나로 변환됩니다. 잘못 변경될 가능성이 있으므로, 확인 후 등록을 권장합니다.
새로 입력된 표기와 읽기로 중복된 단어가 없는 지 검색을 하며, 이미 등록된 단어에 저장할 수도 있습니다.

등록된 단어에는 뜻을 등록가능합니다.

### 자동 단어 등록

- 현재 영상에 등록한 단어가 없는 경우 `mecab`를 통해 자동으로 단어를 등록 할 수 있습니다.

- OPENAI_API_KEY가 환경변수에 있는 경우 단어의 `뜻 정보`도 함께 등록할 수 있습니다.

## 번역

문장에 번역을 등록시, 새로 저장, 수정, 삭제의 기본적인 버전 관리가 가능합니다. 여러 개의 번역 중 하나만을 대표로 선택할 수 있습니다.

## 공유 기능

- URL을 통해 공유할 수 있습니다. 데이터가 URL에 저장되며, 기본적으로 `원문`, `번역문`, `읽기 정보`가 포함됩니다.

### URL길이를 초과하는 경우

- `범위를 지정`해서 일부만 공유할 수 있습니다.

- 혹은, `읽기 정보`를 제외하고 공유하거나, `번역문`과 `원문`중 한가지만 공유할 수 있습니다.

- 또는 `공개적으로 업로드`하여 공유할 수 있습니다. `축약된 URL`을 얻을 수 있으며, 이를 통해 공유할 수 있습니다.

### 내보내기 기능

- 내보내기 기능이 추가되었습니다. `json파일`로 저장하거나, `youtube자막 형식`으로 저장이 가능합니다. json 파일의 경우 추후 PremierePro에서 사용하는 `Extend script` 리포지터리에서 사용합니다.

> [!CAUTION]
> 해당 일본어 폰트에서 전각 공백이 한자 한글자의 크기와 일치하는 폰트에서 원활히 표시 됩니다.

- Adobe PremierePro의 mogrt(모션 그래픽 템플릿) 파일에서 작동을 염두에 두고 만들었으며, 원문과 후리가나 문자열을 반환합니다.

- 이를 추후 배포 예정인 mogrt에 입력 시, 후리가나가 해당하는 한자위에 표시됩니다.

## 단어장을 pdf로 내보내기

- 단어장을 pdf로 변환이 가능해졌습니다.

- 단어만 내보내는 경우, 해당 단어를 `포함하는 문장` 및 `번역`, `단어 다른 읽기 정보`가 포함됩니다.

- 한자만 내보내는 경우, 해당 한자를 `포함되는 단어`가 옆에 나열됩니다.

## 부가 기능

### 한글 -> 히라가나 변환 기능

웹페이지 이용시, 대체로 히라가나 입력이 필요한 단점이 존재. 이를 이용하기 위해, 사용자가 일본어 키보드를 설치해야하는 점과, 반복적인 키보드 전환이 사용에 있어서 불편함을 야기할 수 있기 때문에, 한글을 히라가나로 전환하는 기능을 추가하였습니다.

한글과 가장 가까운 히라가나로 맵핑하며, 장음은 `-`문자 또는 앞의 음에 맞게 변경합니다.

이 기능은 단어 등록시 `읽기 입력`, `단어장 검색`등의 기능에서 지원됩니다.

### 히라나가나 -> 한글 변환 기능

- DB페이지에서 읽는법을 제공하기 위해 제한적으로 사용되고 있습니다.

### DB페이지

- 현재까지 등록된 단어를 모두 볼 수 있습니다.

- 해당 단어의 표기에 따라, 단어가 포함된 영상에 따라 분류되며, 검색은 `표기`혹은 `읽기`로 가능합니다.
